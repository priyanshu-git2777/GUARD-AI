# Security Policy

## Supported versions

TraceDefend AI is not publicly released yet.

## Reporting a vulnerability

Do not open a public GitHub issue for a suspected vulnerability.

Until a dedicated security email is configured, contact the repository owner privately through an appropriate verified channel.

Include:

- A clear description
- Affected feature
- Steps to reproduce
- Potential impact
- Screenshots or logs with secrets removed

Do not:

- Access another user's data
- Modify or delete data
- Run denial-of-service tests
- Upload malware
- Publish the issue before it is reviewed

## Security limitations

This project is under active development and must not be used as a replacement for professional incident response, antivirus software or enterprise security monitoring.
