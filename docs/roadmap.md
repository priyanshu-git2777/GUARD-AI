# Delivery Roadmap

## Phase 1 — Foundation

- Part 1: Product contract, repository rules and definition of done
- Part 2: Monorepo, Next.js, Spring Boot and Docker development environment
- Part 3: UI design system and public landing pages
- Part 4: Backend API conventions and PostgreSQL migrations

## Phase 2 — Identity and user experience

- Part 5: Registration and password security
- Part 6: Email verification and password reset
- Part 7: Login, sessions, CSRF and logout
- Part 8: Workspaces, roles and authorization
- Part 9: Frontend authentication and onboarding
- Part 10: Real dashboard shell

## Phase 3 — Input and processing

- Part 11: Secure file upload
- Part 12: Text and stack-trace submission
- Part 13: Object storage and retention
- Part 14: Normalized event model
- Part 15: Initial log and stack-trace parsers
- Part 16: RabbitMQ analysis jobs and worker
- Part 17: Progress tracking and failure recovery

- Part 18: Deterministic security rule engine
- Part 19: Developer error classifier and fingerprinting

## Phase 5 — Product workflows

- Part 24: Findings dashboard
- Part 25: Incident workflow
- Part 26: Reports
- Part 27: Notifications
- Part 28: Admin operations
- Part 29: Audit logs

## Phase 6 — Production readiness

- Part 30: Automated test suite
- Part 31: Security verification
- Part 32: Performance testing
- Part 33: Observability
- Part 34: Production Docker images
- Part 35: Staging
- Part 36: Production deployment
- Part 37: Backup and recovery
- Part 38: Privacy, support and responsible disclosure
- Part 39: Beta users and feedback
- Part 40: Public launch

## Phase 7 — Later integrations

- Part 41: Read-only AWS connection
